Nothing — but the kit needs one change

No new colour, radius, spacing step, type size or duration. The spinner runs on --dur-ring, which already exists for the dial's ring-in, so the --t-spin proposed in the earlier pass is withdrawn. What is missing is not a token but a prop: Button destructures a fixed list and spreads nothing onto its element, so aria-disabled cannot reach the DOM through it. The Locked control is therefore a native button drawn to match secondary exactly. Button needs an aria-* pass-through.
