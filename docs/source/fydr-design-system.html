06

Replicate it

Four moves to stand up the whole look.

Drop in the token block

Paste the two :root blocks (light base + [data-theme="dark"]) and the brand values. Everything downstream reads these variables.

Load the type

Wire Sora and DM_Mono from next/font/google to --font-sora / --font-mono. Body uses Sora; add .mono to any number.

Build on the primitives

Compose from .card, .btn-primary, .squad-chip, .pill, .field, .stat. Style through tokens, never raw hex — that keeps both themes free.

Reskin by swapping ~7 values

To pivot the identity, change only the brand block — --accent, --accent2, --good, --highlight, --avatar-text, --tab-active. The navy Blue → a green/pink variant in one edit.
